about=Transformer is a controlled vector and tabular data preparation workbench for QGIS 3.40 LTR (Qt 5) through QGIS 4.x (Qt 6). It lets both non-specialists and GIS professionals clean attributes, filter features, apply geometry expressions before reprojection, inspect Before/After diffs, save replayable JSON recipes, run native QGIS Processing algorithms (Graphical Modeler, batch, qgis_process) or the headless Python API (Transfomer.api), and deliver verified multi-format files or transactional PostgreSQL/PostGIS updates without ever modifying source layers.
    Atelier de préparation vectorielle et tabulaire QGIS (3.40 LTR à 4.x, Qt 5 / Qt 6) : nettoyage et filtrage guidés sans formule, expressions QGIS natives, comparaison Avant/Après, recettes rejouables, fournisseur Processing natif, API Python headless, guide HTML interactif en dock QGIS, export multi-formats contrôlé et publication PostgreSQL transactionnelle.
    Verified on QGIS 3.40.15 LTR (Qt 5.15) and QGIS 4.2.1 (Qt 6.11).
